# Tamil Astrology Website

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Vercel
Push this folder to GitHub and import the repository in Vercel. Framework: Next.js. Build command: `npm run build`.

## Important
The UI currently does not claim to calculate real astronomical birth charts. Connect a validated ephemeris/astrology calculation service before presenting planetary positions, lagna, dasha, or matching results as calculated facts.
